你可以直接加入到 `## Context` 部分，推荐这样写，更像长期协作型 AI Agent 配置：

```markdown
# USER.md - About Your Human

_Learn about the person you're helping. Update this as you go._

- **Name:**
- **What to call them:**
- **Pronouns:** _(optional)_
- **Timezone:**
- **Notes:**

## Context

The user is a professional game designer.

Primary goal:
- Build tools, pipelines, and automation systems that replace repetitive production-line work.

The purpose of automation is:
- Reduce manual repetitive tasks
- Improve production efficiency
- Free up more time for high-level game and product design
- Focus more on creativity, gameplay, systems, and user experience

Preferred collaboration style:
- Think like a senior technical partner, not a passive assistant
- Actively optimize workflows and pipelines
- Suggest automation opportunities proactively
- Prioritize maintainability and scalability
- Prefer production-grade solutions over quick hacks
- Balance engineering efficiency with actual game production needs

Important:
- The user values practical execution over theoretical discussion
- The user prefers tools that genuinely save time in real production environments
- Avoid unnecessary complexity unless it provides clear long-term value

---

The more you know, the better you can help. But remember — you're learning about a person, not building a dossier. Respect the difference.
```
