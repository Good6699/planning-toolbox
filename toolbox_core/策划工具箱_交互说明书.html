策划工具箱交互说明书

功能总览

功能子功能一句话
SVN 记录修改摘要统计指定日期范围内各版本的修改文件和提交信息
对比 Excel逐版本对比 Excel 文件差异，输出变更行报告
导出文件导出指定日期范围内修改过的文件到本地目录
语义合并版本合并从源分支筛选版本和变更文件，合并到目标工作副本
Texts.xlsm 合并对 Texts.xlsm 做单元格级逐版本合并，不整文件替换
复制合并文件复制从源目录选文件复制到 SVN 目标目录并辅助提交
翻译AI 翻译调用 AI API 批量翻译 Excel 多语言列，支持参考文件和自定义 Prompt
文字检测质量检查检查 Texts.xlsm 的空值、漏翻、占位符不一致、标签丢失、重复 ID
修改预制一键清理文字批量清理 .prefab 文件中的文字引用
图集引用清理扫描预制的图集引用，拖拽规划迁移到目标图集组
字体检测检测预制中的字体引用，批量替换字体名和行间距
辅助功能meta 生成用一个 .meta 模板给目标文件夹批量生成 meta 文件
工作流导出文字表从主 Excel 文件导出文字表，可上传到多个 SVN 目录
合并文字表把多个 Excel 的指定列按 ID 合并到目标文件
合并翻译把翻译完成的 Excel 合入目标文件
SVN 锁定锁定指定文件防止他人修改
SVN 解锁解除文件锁定
SVN 回退回退指定路径的 SVN 修改
打开表格逐个打开 Excel 文件，支持锁定或不锁定两种模式
整合文字表从源目录选文件复制到目标目录
整合错误码从源提取错误码合入目标，语言代码留空自动识别
上传 SVN把本地目录复制到 SVN 工作副本

全局规则

规则说明
贴边自动收缩拖窗口到屏幕左/右/上边缘会自动贴边收缩；鼠标移到收缩区域边缘自动恢复
停止 ≠ 回滚点停止只取消后续操作，已写入的文件和 SVN 状态不会回滚
看 [DONE] 判断完成日志出现 [DONE] 才算任务完整结束；连接中断 ≠ 失败
关闭 = 托盘点 ✕ 不退出程序，缩到托盘；托盘图标右键可退出
任务完成自动通知任务结束后自动弹出系统通知（窗口隐藏时），无需等待

SVN 记录

填 SVN 地址 选模式 设日期/过滤 执行
操作结果
拖入本地工作副本自动反查 SVN URL 填入地址栏
地址栏点"打开文件夹"URL → 打开对应本地副本；本地路径 → 直接打开
选"导出文件"模式输出目录会在执行前被清空
高级设置改文件级配置影响后续所有导出/对比，切换文件名可加载不同预设

语义合并

填源 SVN 地址 填目标工作副本 筛选查询 选版本 语义分析 开始合并
输入约束
源 SVN 地址用来读版本和变更文件，不要和目标路径混用
目标路径必须是本地 SVN 工作副本
操作结果
拖入本地副本到源地址自动检测并填入 SVN URL
变更文件最终动作最新是删除→删除；曾新增→新增；否则→修改
开始合并直接改目标工作副本；可能弹出 TortoiseSVN 提交窗口（需手动确认）

复制合并

选源目录 勾选文件 填目标 SVN 目录 执行
操作结果
源目录变化延迟刷新文件列表；点刷新按钮可立即刷新
点文件行切换勾选（不必点复选框）
清理 changelist清理目标 SVN 目录的遗留 changelist

翻译

选源 Excel 设源/目标语言 配 API 调 Prompt 执行翻译
输入约束
源语言列名必须匹配 Excel 表头（如 zh、SC、::SC::）
Prompt支持 {src_lang} 和 {tgt_lang} 变量
批处理量越大单次请求越重；出错先降批处理量
Prompt 里的格式保护规则（占位符、颜色标签、换行转义）必须保留，被模型改掉会直接影响游戏文本。
操作结果
语言ID高级设置改完影响翻译和文字检测的语言列表
API Key 输入加密保存到配置

文字检测

检测项说明
空值目标语言列为空
漏翻源有值但目标无值
占位符不一致翻译前后占位符（如 {0}）丢失或改变
标签丢失颜色/代码标签翻译后被破坏
重复 ID全局范围检测
操作结果
检测完成如果日志捕获到输出路径，自动打开输出文件所在目录
排除ID配置一行一个 ID，# 开头为注释

修改预制

图集引用清理

拖入 .prefab 文件/目录 选预制 拖源组到目标组 执行计划
操作结果
拖源图集组到目标图集组创建迁移计划（该组下所有引用）
点资源行的指针图标手动指定单个资源的目标 Sprite
点"+"按钮添加当前未引用的图集组作为拖放目标（仅影响当前预制）
图集组旁的数字该组包含的引用资源数
点刷新图标刷新预制最新引用，删除已失效的迁移计划

字体检测

拖入 .prefab 文件/目录 填写目标字体名/行距 预览变更 确认修改
操作结果
拖入预制文件或目录自动遍历 3 层，检测所有字体引用
填写目标字体名留空不改；支持填路径（如 UI/D3Fonts/xxx）
填写行距留空不改；只替换目标字体所在组件的行距，不影响其他字体
点预览变更弹窗显示变更表格：原字体（含路径）→ 目标 → 行距 → 影响文件数
确认修改批量替换 .prefab 文件中的字体 GUID 和行距

辅助功能

拖入 .meta 模板 拖入目标文件夹 自动开始生成
操作结果
拖入 .meta 文件识别为模板
拖入其他路径识别为目标文件夹
两者都就绪自动开始，不需要点"开始"按钮
任务完成自动清空模板和目标，方便下一轮

工作流

树形列表

操作结果
点击工作流标题展开/收起（同时只展开一个）
长按/拖动调整工作流和步骤顺序，松手即保存

复制工作流如果步骤含工程路径前缀（如 H:\D3_EA），弹窗让你一次性替换
