策划工具箱 用户说明书

版本 1.0 — SVN 一键对比 / 上传 / 工作流 / 翻译

1. 概述

策划工具箱是针对游戏策划工作流开发的一站式工具集合，集成以下核心功能：

  • SVN 记录 — 查询 SVN 提交记录，对比 Excel 表格不同版本间的差异，导出变更文件，生成修改总结
  • 上传 SVN — 可视化选择文件并上传至 SVN 服务器
  • SVN 工作流 — 编排多步骤自动化流程（导出文字表 → 上传SVN → 合并表格等）
  • 翻译 — 对接 AI API（DeepSeek / OpenAI），批量翻译游戏 Excel 表格中的文本

1.1 启动方式

提供三种启动入口：

方式文件说明
推荐 策划工具箱GUI.vbs 智能启动器。自动检测 Python 位置，首次运行自动触发环境检测，静默启动主界面
兜底 环境修复.bat 当完全没有 Python 环境时使用。会自动下载安装 Python 3.13、SlikSvn，然后启动工具箱
直接 svn_launcher.py 直接启动（需已安装 Python）。双击 .py 文件或命令行运行
双击 VBS → 查找 Python → 环境检测 → 显示窗口 → 加载模块 → 就绪

1.2 环境检测

首次启动时，setup_checker.py 会自动执行环境检测，检查以下项目：

检测项检查内容失败处理
Python 版本确认 ≥3.10提示安装
SVN 客户端查找 svn.exe 并确认可用提示安装 SlikSvn
Office / WPS注册表检测仅警告，不阻塞
核心脚本检查 10 个必需 .py 文件提示文件缺失

检测通过后会在 _env_cache.json 缓存 Python 路径，下次启动直接读取，无需重复检测。

2. 快速上手指南

2.1 各功能一句话说明

功能一句话说明
SVN记录 查某段时间内谁改了哪些文件，对比 Excel 前后版本差异，或把修改的文件导出到本地
上传SVN 把本地改好的文件勾选后复制到 SVN 目录，一键调起 TortoiseSVN 提交对话框
SVN工作流 把重复的日常操作（导出文字表→上传SVN→合并表格等）编成流程，一键执行
翻译 选一个 Excel 表格，配好 AI 接口，自动批量翻译文本到多种语言

2.2 典型使用场景

场景：每天看看今天改了啥

  1. 打开工具 → 默认就在「SVN记录」页签
  2. 顶栏粘贴 SVN 地址（或直接拖拽工作目录进来自动识别）
  3. 选「总结SVN修改记录」模式 → 点「执行」
  4. 等几秒，AI 自动生成今天所有人改了什么的可读总结

场景：修改 Excel 后提交 SVN

  1. 切到「SVN工作流」页签
  2. 点「+ 新建工作流」→ 添加步骤「合并表格」和「上传SVN」
  3. 配置好文件路径 → 保存
  4. 以后每次改完 Excel，点一下执行就行

场景：翻译多语言 Excel

  1. 切到「翻译」页签
  2. 选需要翻译的 .xlsm 文件
  3. 在「API 配置」里填好地址和 Key（首次设置）
  4. 勾选需要翻译的目标语言列 → 点「开始翻译」
  5. 程序自动分批发送给 AI，翻译完成后保存到输出目录

2.3 操作小技巧

拖拽识别 SVN 地址：在 SVN 记录页签，直接把工作目录中的文件或文件夹拖到 URL 输入框，自动识别 SVN 地址，不用手动粘贴。
窗口位置记忆：调整好窗口大小和位置后关闭工具，下次打开自动恢复位置。如果发现窗口不见了，删除 svn_gui_config.json 中的 window_geometry 行即可重置。
工作流复制：做类似任务时不用重新创建，右键工作流点「复制」，改改参数就行。
翻译提速：「每批条数」默认 20 条，网络好可以调到 50-100 条，翻译速度翻倍。如果报错就调小。
环境修复：换了新电脑解压后，如果双击 VBS 没反应，运行「环境修复.bat」自动装 Python 和 SVN。
筛选今天的提交：在 SVN 记录页签点「今日」按钮，自动填入当天日期，快速查今日改动。
清除缓存：如果觉得工具变慢或异常，点日志区旁边的「清除缓存」按钮。

3. SVN记录页签

SVN记录是工具的核心功能，提供三种操作模式。

3.1 SVN URL 输入

在顶部输入框中填写 SVN 仓库地址：

  • 手动输入 — 直接粘贴 SVN 地址（如 http://192.168.1.41:8080/svn/D3/...）
  • 拖拽识别 — 将 SVN 工作副本中的文件或文件夹拖拽到输入框，自动执行 svn info 识别对应 URL
  • 历史记录 — 点击右侧 ▼ 按钮从历史 URL 中选择

3.2 三种模式

模式功能输出
对比 Excel 修改记录 查询指定日期范围内的 SVN 提交记录，逐文件对比每个版本间的 Excel 差异，输出新增、修改、删除的行明细 Excel 文件（包含 Sheet、ID、变更类型、版本号等内容）
导出 SVN 修改文件 查询指定日期范围内的 SVN 提交记录，将变更的文件导出到本地目录（含修改新增的文件，可排除指定目录） 文件夹（按 SVN 目录结构导出）
总结SVN修改记录 查询指定日期范围内的 SVN 提交记录，调用 AI API 生成可读的修改日志摘要 Markdown / 文本文件

3.3 日期范围

设置查询的开始/结束日期。点击「今日」按钮快速填入当前日期。

3.4 过滤条件

  • 关键词 — 按空格分隔多个关键词，筛选出提交日志中包含任一关键词的记录
  • 提交者 — 指定 SVN 提交者用户名，仅查询该用户的提交

3.5 高级选项

点击「⚙ 高级选项」按钮打开高级设置弹窗：

设置项说明
过滤目录导出模式有效，逗号分隔的目录名列表（如 BinData, Language），匹配到的目录不导出
文件名（预设）对比模式有效，指定只对比某个 .xlsm 文件，可保存为预设
标题行数对比模式有效，Excel 表格的表头行数（默认 1）
对比 ID 列对比模式有效，用作行唯一标识的列名（默认 ::ID::）
全局对比 ID对比模式有效，留空则自动查找
输出列对比模式有效，逗号分隔的列名，留空输出全部列
预设管理可按文件名保存/删除一套对比参数配置

4. 上传SVN页签

用于将本地文件上传/提交到 SVN 仓库。

操作流程

  1. 选择源目录 — 输入或浏览选择要上传的文件所在目录（支持拖拽）
  2. 勾选文件 — 文件列表自动加载，点击复选框勾选需要上传的文件，可全选/取消全选
  3. 选择目标目录 — 输入或浏览选择 SVN 工作副本中的目标目录（支持拖拽）
  4. 点击「上传SVN」 — 工具将勾选的文件复制到目标目录，并调用 TortoiseSVN 提交对话框
提示：目标目录必须是 SVN 工作副本（包含 .svn 文件夹）。上传前可通过「清除changelist」按钮移除"本次修改"变更列表。

5. SVN工作流页签

工作流功能允许将多个操作步骤编排为一个可重复执行的流程，大幅减少重复操作。

工作流管理

  • 新建工作流 — 命名并创建空工作流
  • 复制工作流 — 复制当前选中的工作流
  • 删除工作流 — 删除选中的工作流
  • 拖拽排序 — 左侧树形列表中可直接拖拽调整步骤顺序

5.1 七种步骤类型

步骤类型功能说明配置参数
导出文字表 从 .xlsm 主文件中导出各语言的文字配置文件（.txt）和 protobuf 数据 主文件路径、工具目录、输出目录、语言列表
上传SVN 将指定目录的文件复制到目标目录并提交 SVN 源目录、目标目录、是否提交 TortoiseSVN
合并表格 将多个 Excel 表格合并为一个，支持按行或列追加 输入文件列表、合并方式、输出路径
合并翻译 将翻译后的 Excel 文件合并回主 .xlsm 文件 翻译文件路径、原始文件路径、输出路径
导出错误码 从 Excel 中提取错误码定义并导出为配置文件 根目录路径、输出目录
锁定SVN 对指定目录下的 .xlsm 文件执行 SVN 锁定（防止冲突） 目标目录、文件路径
打开表格 用 Excel 打开指定的文件列表 文件路径列表

执行工作流

  1. 在左侧选中一个工作流
  2. 右侧显示工作流详情和步骤列表
  3. 点击「▶ 执行工作流」按钮
  4. 可选择执行全部步骤或指定步骤范围（如 1-3,5 表示执行第 1 到 3 步和第 5 步）
注意：工作流会自动按顺序执行各步骤。执行过程中可在日志区查看进度。耗时较长的步骤建议等待完成再进行其他操作。

6. 翻译页签

翻译功能对接 AI API，实现游戏 Excel 表格的批量翻译，支持多目标语言。

操作流程

  1. 选择翻译表格 — 选择需要翻译的 .xlsm / .xlsx 文件（支持拖拽）
  2. 选择翻译参考（可选） — 提供已有的翻译结果文件作为参考，AI 会优先使用参考中的翻译
  3. 配置 API — 填写 API 地址、Key 和模型名称
  4. 选择语言列 — 程序自动识别表头，选择源语言列和需要翻译的目标语言列
  5. 点击「开始翻译」 — 逐批发送给 AI API，实时显示进度

6.1 API 配置

参数说明示例
API 地址兼容 OpenAI 接口格式的 API 端点https://api.deepseek.com/v1/chat/completions
API Key认证密钥sk-xxxxxxxxxxxx
模型使用的模型名称gpt-4o-mini / deepseek-chat

6.2 语言列检测与映射

工具会自动读取 Excel 表头，通过 lang_map.txt 映射表识别每列对应的语言：

  • 简体中文 — 自动识别为源语言
  • 繁体中文、英语、日语、韩语、泰语… — 自动勾选为目标语言
  • 支持通过「编辑语言映射」用记事本自定义映射规则

格式（lang_map.txt）：

# 关键词=语言名
ko_kr=韩语
ja_jp=日语
th_th=泰语
id_id=印度尼西亚语
vi_vn=越南语
zh_hk=繁体中文

高级设置

  • 提示词 — 可自定义发送给 AI 的系统提示词
  • 每批条数 — 每次 API 调用发送的文本行数（默认 20，增大可提升翻译速度但可能降低质量）
  • 输出路径 — 翻译结果保存位置
提示：API 调用是异步并发的，多个目标语言同时翻译。如果遇到限流，可减小每批条数。

8. 常见问题

双击 VBS 没有反应

  • 尝试右键 → 用「Microsoft (R) Console Based Script Host」打开
  • 运行同目录下的 环境修复.bat 检查并修复环境
  • 确认 Python 3.10+ 已安装且路径正确

SVN 功能报错 "未找到 svn 命令"

  • 安装 SlikSvn（https://sliksvn.com/download/）
  • 或安装 TortoiseSVN 并确保安装时勾选了「命令行工具」
  • 安装后重启工具箱即可

翻译时 API 报错

  • 确认 API 地址和 Key 填写正确
  • 确认网络可以访问 API 服务器
  • 尝试减小「每批条数」避免超时
  • 部分模型需要特定格式的 API 地址，参考模型提供商的文档

Excel 写入失败

  • 确认 .xlsm 文件没有被 Excel 或 WPS 打开（会触发文件锁）
  • 确认已安装 WPS Office 或 Microsoft Excel
  • 如使用 WPS，确认 WPS 安装完整（含 VBA 支持）

分发包解压后不能用

  • 确认解压路径不包含中文字符或空格（部分 Python 包对路径敏感）
  • 运行 环境修复.bat 自动检测并修复环境问题
  • 确认解压时保持了目录结构（不要只解压 .exe 文件）

如何更新工具箱

  • 替换所有 .py 脚本文件和 lang_map.txt
  • py_modules 目录通常不需要替换，除非有新的第三方依赖
  • 删除 _env_cache.json 让程序下次重新检测环境
  • 配置文件 svn_gui_config.json 保留不动即可保留设置
