# AI执行文档 — Unity 多工程 SVN 智能增量合并系统

## 项目名称

```text
UnitySVNMergeTool
```

---

# 一、项目目标

开发一个：

# Unity 多工程 SVN 智能增量合并工具

用于：

* 从源 Unity 工程 SVN 历史中筛选指定提交
* 自动提取增量文件
* 自动同步到目标 Unity 工程
* 自动处理新增/修改/删除
* 自动保护 Unity GUID/meta
* 自动解决冲突
* 自动同步 SVN 状态
* 自动弹出 SVN 提交窗口

---

# 二、核心原则（最高优先级）

# 1. 禁止使用 svn merge

绝对禁止：

```bash
svn merge
```

原因：

* 会生成 mergeinfo
* 会产生树冲突
* 会修改工作副本状态
* Unity YAML 极易炸引用

---

# 2. 禁止全工程 revert

绝对禁止：

```bash
svn revert -R .
```

原因：

会清空本地文件。

---

# 3. 使用“文件级增量同步”

工具本质：

```text
SVN差异提取
+
文件同步覆盖
+
Unity资源保护
```

而不是：

```text
传统SVN合并
```

---

# 三、系统定位

本工具不是 SVN 客户端。

本工具是：

# Unity SVN 增量迁移系统

# 八、Unity资源保护系统（核心）

# 1. meta强绑定规则

任何 Unity 资源：

```text
prefab
scene
mat
asset
anim
controller
shader
```

必须：

```text
资源
+
.meta
同步处理
```

---

# 2. GUID保护规则

如果目标工程已存在资源：

且：

```text
GUID不一致
```

禁止：

```text
覆盖.meta
```

只能：

```text
覆盖资源本体
```

否则：

会导致：

* prefab丢引用
* scene missing
* script missing

---

# 3. 文件夹meta规则

Unity 文件夹也存在：

```text
folder.meta
```

必须同步。

---

→ 创建目标备份
